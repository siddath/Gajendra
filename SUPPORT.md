# Support

Gaja is a community-supported open-source project.

- Use [GitHub Discussions](https://github.com/siddath/Gajendra/discussions) for setup questions, integration ideas, and general help.
- Use the [bug report form](https://github.com/siddath/Gajendra/issues/new?template=bug.yml) for reproducible defects containing synthetic data only.
- Use [private vulnerability reporting](https://github.com/siddath/Gajendra/security/advisories/new) for security issues.

Do not post prompts, transcripts, credentials, access tokens, private repository names, or real provider thread identifiers. A response time or fix is not guaranteed.
