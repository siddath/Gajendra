# Support

Gajendra is a community-supported open-source project.

- Use [GitHub Discussions](https://github.com/siddath/Gajendra/discussions) for setup questions,
  integration ideas, and general help.
- Use the [bug report form](https://github.com/siddath/Gajendra/issues/new?template=bug.yml) for
  reproducible defects with synthetic data only.
- Use [private vulnerability reporting](https://github.com/siddath/Gajendra/security/advisories/new)
  for security issues.

Current source-candidate evidence and open release gates are in [STATUS.md](STATUS.md). Do not
include private rollout, prompt, transcript, credential, or absolute-path data in a support report.
